# ECG Arrhythmia Detection and Classification Using Hidden Markov Models (HMM)

An end-to-end, research-grade machine learning system for detecting and classifying cardiac arrhythmias across the **complete 48-recording MIT-BIH Arrhythmia Database** (PhysioNet) in accordance with the **ANSI/AAMI EC57:1998** standard.

---

## 1. Project Overview & Clinical Rationale

An Electrocardiogram (ECG) measures the biopotential voltages generated by the electrical conduction system of the human heart during successive cardiac cycles. Cardiac arrhythmias—disturbances in rhythm, rate, or origin of cardiac excitation—can range from benign irregularities to life-threatening conditions such as Ventricular Tachycardia (VT) and Ventricular Fibrillation (VF).

Most standard machine learning models treat ECG heartbeats as static, independent tabular vectors, ignoring the underlying time-dependent, multi-phase biological activation of myocardial tissue. 

This project implements **Class-Conditional Continuous Gaussian Hidden Markov Models (G-HMM)** to explicitly capture the physiological sub-phases of the cardiac cycle:
1. **Atrial Depolarization** (P-wave)
2. **AV Nodal Conduction Delay** (PR-segment)
3. **Ventricular Depolarization** (QRS-complex)
4. **Ventricular Plateau** (ST-segment)
5. **Ventricular Repolarization** (T-wave)

---

## 2. Dataset Specifications

- **Database:** MIT-BIH Arrhythmia Database (PhysioNet).
- **Scope:** Complete **48 two-channel ambulatory ECG recordings** (Records 100–124 and 200–234).
- **Duration:** 30 minutes per record ($\approx 1,800\text{ s}$ each, totaling 24 hours of ECG data).
- **Sampling Frequency:** $360\text{ Hz}$ with 11-bit resolution over a $10\text{ mV}$ range.
- **Leads:** Modified Lead II (MLII) as the primary evaluation lead, accompanied by modified leads V1, V2, V4, or V5.
- **Reference Annotations:** Cardiologist-validated beat locations and clinical arrhythmia symbols in `.atr` files.

---

## 3. AAMI Standard Heartbeat Categorization

In compliance with the **ANSI/AAMI EC57:1998 standard**, 15+ detailed MIT-BIH rhythm symbols are systematically consolidated into **5 clinically actionable superclasses**:

| AAMI Class | Clinical Meaning | MIT-BIH Annotation Codes Included |
| :---: | :--- | :--- |
| **N** | Normal & Bundle Branch Block beats | Normal (`N`), Left bundle branch block (`L`), Right bundle branch block (`R`), Atrial escape (`e`), Nodal escape (`j`) |
| **S** | Supraventricular Ectopic Beats (SVEB) | Atrial premature (`A`), Aberrated atrial premature (`a`), Nodal premature (`J`), Supraventricular premature (`S`) |
| **V** | Ventricular Ectopic Beats (VEB) | Premature ventricular contraction (`V`), Ventricular flutter wave (`!`), Ventricular escape (`E`) |
| **F** | Fusion Beats | Fusion of ventricular and normal beat (`F`) |
| **Q** | Paced & Unclassifiable Beats | Paced beat (`/`), Fusion of paced and normal (`f`), Unclassifiable beat (`Q`) |

*Non-beat markers (rhythm changes `[`, `]`, noise annotations `~`, `|`, isolated measurement artifacts) are explicitly identified and excluded from beat classification.*

## 5. Strict Inter-Patient Partitioning (Zero Data Leakage)

A known pitfall in biomedical machine learning is **intra-patient data leakage** (randomly shuffling beats from the same recording across train and test sets), which inflates reported accuracies to 98–99% without testing clinical generalization.

This project strictly adheres to the **inter-patient paradigm** (de Chazal et al., 2004):
- **Train Set (24 records):** `101, 102, 106, 108, 109, 112, 114, 115, 116, 118, 119, 122, 124, 201, 202, 203, 205, 207, 208, 209, 215, 220, 223, 230`
- **Validation Set (4 records):** `104, 107, 217, 222`
- **Independent Test Set (20 records):** `100, 103, 105, 111, 113, 117, 121, 123, 200, 210, 212, 213, 214, 219, 221, 228, 231, 232, 233, 234`

> [!IMPORTANT]
> In the MIT-BIH Arrhythmia Database, **Record 201 and Record 202 originate from the exact same patient**. In this project, both 201 and 202 are strictly co-located in the training pool, guaranteeing zero patient overlap between train, validation, and test sets.

## 8. Biological Interpretability with Viterbi Decoding

Unlike black-box neural networks, the Hidden Markov Model provides direct physiological transparency. By applying the Viterbi algorithm to an observation sequence:
- **State 0:** Atrial depolarization ($P$-wave)
- **State 1:** AV conduction delay ($PR$-segment)
- **State 2:** Ventricular depolarization ($QRS$-complex)
- **State 3:** Ventricular plateau ($ST$-segment)
- **State 4:** Ventricular repolarization ($T$-wave)

Visualizing the decoded hidden state trajectory over the ECG waveform confirms that the model discovers the genuine electrophysiological sequence without manual wave-boundary segmentation.
